========================
JavaScript for Loop
========================

# for Loop
Used to repeat code multiple times.

# Basic Syntax
for (initialization; condition; increment/decrement) {
    // loop statement
}

# 3 Parts of for Loop
1. Initialization → starting value
2. Condition → loop runs while true
3. Increment/Decrement → updates value

** for	loop is you already know how many times the loop should run
** while loop is Used when number of iterations is NOT known beforehand

# while Loop Version
let num = 1;

while (num <= 5) {
    console.log(num);
    num++;
}

# Same Code Using for Loop
for (let number = 1; number <= 5; number++) {
    console.log(number);
}

Output:
1
2
3
4
5

# number++
Shortcut for:
number = number + 1

# Even Numbers
for (let i = 0; i <= 10; i = i + 2) {
    console.log(i);
}

Output:
0
2
4
6
8
10

# Odd Numbers
for (let i = 1; i <= 10; i = i + 2) {
    console.log(i);
}

Output:
1
3
5
7
9

# Important Notes
- Use let inside loops
- i is commonly used as loop variable
- Increment means increasing value
- Decrement means decreasing value

# Best Practice
Always:
- set proper condition
- update loop variable
